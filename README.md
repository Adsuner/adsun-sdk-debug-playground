# Adsun SDK Debug Playground

Load the canonical SDK and inspect debug advertising outcomes.

## What this repository contains

Independent educational example code and public documentation only. It contains no existing Adsun application source, SDK implementation, account tokens, environment files or production data.

## Quick start

Serve this folder locally with `python3 -m http.server 8000`, then open http://localhost:8000.

## Integration and limitations

Use a public publisher block ID. Debug is always enabled in this example: test ads are not billed and do not call the Reward URL. For production use an approved Telegram Mini App platform and active block, disable debug and verify valuable rewards server-side. Local balances/hints are demonstrations, not proof of payment. SDK is loaded by URL only; no SDK implementation is copied.

## SDK and public sources

- Canonical Mini App SDK URL: https://api.adsun.io/sdk.js
- Official reference: https://adsun.io/documentation/publisher/api-reference
- Testing: https://adsun.io/documentation/publisher/testing
- Adsun: https://adsun.io
